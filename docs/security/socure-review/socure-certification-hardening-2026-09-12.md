## N3 — Nullability

`socureEvaluationResponseSchema` / `socureEvaluationCompletedEventSchema`: informational fields (`score`, `notes`, `sub_status`, `tags`, `reason_codes`, `decision_tags`, `review_queues`, `eval_at`, `decision_at`, `workflow_id`, empty `environment_name`) are nullable/optional; `data_enrichments[]` items accept `response: null` (failed enrichment → recorded as `failed`, evaluation still parsed and decided by `decision`/status). ## N4 — Missed-webhook reconciliation

- Client: `getEvaluation(evalId)` → `GET /api/evaluation/{eval_id}` through the same request builder (pinned `X-API-Version`, timeout, correlation id); `include_input` never sent.
- Adapter: `reconcile(subject)` — non-terminal + has eval_id only; bounded backoff 30 s → 2 min → 10 min → 30 min → 60 min recorded on `record.reconcile`; `not_due` short-circuits without a provider call; still-paused keeps state; outage/mismatch → `provider_error` (retryable, never a rejection); terminal → `finalizeProviderResult` with synthetic event id `reconcile:<eval_id>:<decision>`.
- Single finalization: `applyWebhook` and `reconcile` both call `finalizeProviderResult` → `applyFinalProviderDecision` (one call site, asserted); a later real webhook for the same result is `idempotent_same_result` (no duplicate history/evidence), a conflicting one `conflict_flagged`.
- BFF: `POST /api/v1/investor/kyc/reconcile` (`reconcileKycEvaluation`, bffMutate, session-scoped, same-origin, Signal-allowed); the browser never calls RiskOS.
- Browser triggers: page resumed/refreshed with a non-terminal journey that has an evaluation, DocV `onSuccess` (after "captured"), relevant DocV `onError` outcomes.
- Stale-evaluation recovery model: user-initiated reconciliation now; a bounded server-side sweep for stale non-terminal evaluations (`reconcile.notBefore` elapsed, capture reported but no final webhook) is designed but not scheduled — to be enabled with B once a live asynchronous case exists.
- **Scenario M — PASS (FIXTURE DRIVEN)**: non-terminal under-review journey, no webhook, GET returns terminal ACCEPT → `passed`, final evidence, one history entry, audited synthetic event; late webhook → `idempotent_same_result`, no duplicate; REJECT via GET → `failed`; paused → `still_pending`; 503 → `provider_error` + backoff + `not_due`; wrong environment refused; terminal / no-eval → no provider call. To be repeated live with B.
