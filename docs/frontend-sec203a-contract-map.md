## J. Forbidden Mappings (Explicit)

The following must **never** appear in any investor-facing route:

| Forbidden mapping                                                                   | Why                                                                                                                                                             |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `template.admin action=rebalance target_account_id=X` ↔ investor button             | This is an admin operational command. Making it investor-acceptance contradicts software-as-adviser and routes per-trade approval through a human-style action. |
| `acceptRecommendation` / `approveTrade` ↔ investor button                           | Per-trade investor approval contradicts the managed-advisory program model and creates ambiguity about who originated the advice.                               |
| Admin operator approving / editing / supplementing a client-specific recommendation | Direct rule violation (no human-authored advice).                                                                                                               |
| Off-platform delivery channel (email, SMS, PDF report) of client-specific advice    | Rule requires exclusive platform delivery.                                                                                                                      |
| Support staff authoring "what to buy / sell / hold" responses                       | Rule + support-fence already enforced; double-check backend RBAC.                                                                                               |
