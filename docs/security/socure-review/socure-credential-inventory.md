# Socure activation credential inventory (no values)

Names as proven by `apps/web/src/lib/config/env.ts`. The directive's `SOCURE_SDK_KEY` is `NEXT_PUBLIC_SOCURE_SDK_KEY` in code (public by design).

| Variable                           | Class                           | Reaches                                      | Sandbox / Production                                                                              | Intended location                                                                   | Rotation                                            |
| ---------------------------------- | ------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| `REFI_KYC_PROVIDER`                | config                          | server                                       | both (`socure`)                                                                                   | deployment env                                                                      | n/a                                                 |
| `SOCURE_API_BASE_URL`              | config                          | server                                       | `https://riskos.sandbox.socure.com` / `https://riskos.socure.com` (host enforced by `SOCURE_ENV`) | deployment env                                                                      | n/a                                                 |
| `SOCURE_ENV`                       | config                          | server                                       | `sandbox` / `production`                                                                          | deployment env                                                                      | n/a                                                 |
| `SOCURE_WORKFLOW_NAME`             | config (not secret, not public) | server                                       | per environment                                                                                   | deployment env                                                                      | when the workflow is republished                    |
| `SOCURE_API_KEY`                   | **secret**                      | server only (Authorization header to Socure) | separate keys per environment                                                                     | Secret Manager `socure-api-key-<env>`                                               | on exposure; at least annually; on personnel change |
| `SOCURE_WEBHOOK_BEARER_TOKEN`      | **secret**                      | server only (compared constant-time)         | per environment                                                                                   | Secret Manager `socure-webhook-bearer-<env>`; mirrored in the RiskOS webhook config | on exposure; annually                               |
| `SOCURE_WEBHOOK_ENFORCE_SENDER_IP` | config                          | server                                       | `0` until the runtime exposes the true source address                                             | deployment env                                                                      | n/a                                                 |
| `NEXT_PUBLIC_SOCURE_SDK_KEY`       | public key                      | browser + server                             | per environment                                                                                   | deployment env (Vercel/Cloud Run public env)                                        | on dashboard rotation                               |

Browser may receive only `NEXT_PUBLIC_SOCURE_SDK_KEY`. No `NEXT_PUBLIC_` prefix exists for any server secret (asserted in CI).
