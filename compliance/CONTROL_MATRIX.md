# Control Matrix (living document)

This file maps each regulation-relevant technical control in this repository to
(a) the code that implements it, (b) the automated test or CI gate that verifies
it, and (c) its current evidence status. It exists so that "we have a control
for that" is always a checkable claim against a real file and a real gate — not
an assertion.

**Update rule:** any PR that touches a control's implementing code (the files in
the "Implementing code" column) MUST update that control's row in this file —
re-run the verifying gate, refresh the Status date, and adjust the code/test
references if they moved. A PR that adds a new gate or removes one must add or
delete the corresponding row. Reviewers should treat a stale row like a failing
test. A control retired with its surface keeps its row, marked RETIRED with the
PR that removed it — never deleted.

**Regulatory hooks are DRAFTS.** Every entry in the "Regulatory hook" column is
an engineering-side suggestion of the plausibly relevant regime and is marked
"DRAFT — confirm with counsel". None of it is a legal determination. See
`compliance/README.md`.

**Verification legend:**

- `VERIFIED 2026-08-24 (CI)` — the named gate runs as a **blocking CI job** on
  every push/PR (`.github/workflows/ci.yml`) and passed on `main` most recently
  at the merge of PR #56. Since PR #47 this includes the full Playwright suite
  against the **production artifact** (`pnpm e2e`, 46 tests) and the
  **signal-stage lane** (`pnpm e2e:signal`, 10 tests) — the prior matrix's
  statement that e2e is not wired into CI has been false since #47 and is
  corrected here.
- `VERIFIED 2026-08-24 (local)` — the named gate was additionally re-run on
  this working tree on 2026-08-24 and passed (`pnpm typecheck`, `pnpm lint`,
  `pnpm test` = contract-test + tripwire + unit, `pnpm e2e`, `pnpm e2e:signal`).
- `UNVERIFIED` — no automated test or gate exercises this control in the
  current tree.
- `RETIRED (PR #52)` — the surface this control governed was structurally
  removed with the Managed product (C2a); the row is retained as history and
  the REMOVAL itself is now the verified control (see IB-10).

File references are `path` plus symbol/behavior; line numbers are avoided where
they churn. Baseline: branch `compliance/control-matrix-rewrite` off
`main @ 5e76993`, 2026-08-24.
