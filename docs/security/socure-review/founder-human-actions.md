# Founder human actions (one page) — training and endpoint

## Security awareness training (required for YES)

1. Open `docs/security/socure-review/security-training-package.md` (v1).
2. Read the nine topics (about 15–20 minutes).
3. Complete the ten-question quiz at the end.
4. Score at least 8/10 (retake after re-reading if lower).
5. Enter into `training-completion-checklist.md`: name, date, training version (v1 2026-09-10), score, acknowledgment (signed/method), next due date (one year).
6. Tell engineering; the evidence record is updated only after your confirmation, with the actual date (never backdated).

## Endpoint security (required for YES) — your current Mac

1. **Firewall:** System Settings → Network → Firewall → On; Options → Stealth mode On.
2. **Idle lock:** System Settings → Lock Screen → Start Screen Saver when inactive: 15 minutes or less; Require password after screen saver begins or display is turned off: Immediately; display sleep ≤ 15 minutes.
3. Manually confirm: Touch ID + strong password; Remote Login off (General → Sharing) unless explicitly required; Find My Mac on; Chrome/Safari current with automatic updates on.
4. Tell engineering; the read-only check is re-run and recorded. Any other device with customer-data access must be checked before the organizational answer becomes YES.
