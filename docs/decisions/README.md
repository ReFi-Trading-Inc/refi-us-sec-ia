# Decisions

This directory holds the maintained partner/phase decision log for the ReFi investor product.

- `DECISION_LOG.md` is the single source of truth for decisions with Daniel and phase-level decisions (Phase 2.5 onward). It was seeded 2026-08-08 from `Dan_Decision_Tracker_ReFi_Phase2_5.xlsx` (a stale 2026-05-29 snapshot) and reconciled the same day against `docs/phase2-6-daniel-answer-resolution.md` and `docs/phase2-7-daniel-direction-resolution.md`; the log, not the spreadsheet, is authoritative going forward.
- Append new decisions with a date and owner; edit status changes in place. Never delete entries — supersede them.
- Every entry keeps: ID, status (DECIDED / OPEN / BLOCKED), owner, question/decision, context, and impact.
- Partner emails and briefs (e.g., decision requests to Daniel) should be drafted FROM this log, and Daniel's replies recorded back into it (Dan answer / Decision outcome fields).
