# PII inventory — ReFi-owned KYC via Socure (mandate §9)

Principle: collect once, transmit once, retain references — not artifacts. Every identity value is validated and normalised in memory by the BFF, sent to Socure in one Evaluation request, and dropped. ReFi retains the provider-neutral evidence record (`lib/kyc/evidence.ts`: ids, decisions, component statuses, timestamps, provenance) — never the values below. Contract assertions enforce that evaluation records, outcomes, receipts and errors contain none of them.
